아직 더 고치거나 원복하지 마. 현재 바뀐 파일과 diff, 진행 중인 프로세스, 이미 실행된 외부 동작(DB·메일·결제·배포·API), 보존할 내 기존 변경을 먼저 보여줘. 복구 후보마다 정확한 대상과 사라질 항목, Git으로 돌아오지 않는 상태, 확인 방법을 보고해. 내가 범위를 승인하면 그 부분만 복구하고 사고 전 완료 조건으로 다시 검증해.

구분무엇을 멈췄는가

Esc는 현재 Claude 동작을 멈추는 수단입니다. 이미 실행된 배포·결제·발송을 자동 취소하지 않으며, 별도 프로세스가 계속 도는지도 확인해야 합니다.

금지손실 미리보기 없는 일괄 복구

git reset --hard, 전체 checkout·clean, 디렉터리 삭제 같은 파괴 명령을 대상 확인 없이 복사하지 않습니다.

복구 완료 확인

  • 복구 대상만 되돌아왔고 사용자 변경은 남아 있음
  • DB·메일·결제·배포·외부 API 결과를 별도로 확인함
  • 사고 전과 같은 입력·환경·완료 조건으로 재검증함
  • 원인과 방지책을 현재 기록과 안정된 규칙에 분리함

핵심: Git은 추적해 커밋한 파일의 이력입니다. 외부 세계와 모든 로컬 상태를 되돌리는 만능 복구 버튼이 아닙니다.
