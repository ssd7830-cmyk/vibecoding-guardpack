# 증거 기반 진단과 수리

이 파일은 라우터일 뿐이며 진단 절차의 정본이 아니다.

1. 먼저 Read 도구로 `${CLAUDE_PLUGIN_ROOT}/03-진단-수리-분리.md` 정본을 끝까지 읽는다.
2. 현재 요청이 원인 보고인지 실제 수정인지 먼저 구분한다. 보고 전용 요청에서는 쓰기 probe나
   repair patch를 수행하지 않는다.
3. 정본의 게이트를 적용하되, 원인과 수정이 직접 관찰되는 명백한 저위험 작업이나 명확한 신규
   기능을 억지 진단 절차로 막지 않는다.
4. 긴 세션 정리, 외부 문서의 지시 경계, 세션 인계가 주된 문제라면 이 라우터의 범위를 넓히지
   말고 컨텍스트·의도 라우터로 구분한다.

관찰 결과가 다음 판단을 바꾸지 않으면 탐색 범위를 더 넓히지 않는다.
