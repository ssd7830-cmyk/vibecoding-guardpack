# 완료 주장 검증

이 파일은 라우터일 뿐이며 완료 기준의 정본이 아니다.

1. 먼저 Read 도구로 `${CLAUDE_PLUGIN_ROOT}/02-완료-검증-가드.md` 정본을 끝까지 읽는다.
2. 사용자가 요구한 결과와 제외 범위를 기준으로 검증한다. 현재 요청이 보고 전용이면 파일이나
   외부 상태를 바꾸지 않는다.
3. 각 중요한 주장에 실제 실행 증거를 연결하고, 증거가 닿지 않는 범위는 미검증으로 남긴다.
4. 단순 문구 수정이나 명백한 저위험 작업에 긴 완료 계약과 형식 채우기를 강제하지 않는다.

출처의 신뢰성 자체가 핵심인 조사·비교는 이 스킬의 범위를 넓히지 말고 근거 검토 라우터의
범위로 구분한다.
