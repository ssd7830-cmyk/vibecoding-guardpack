# 근거와 고영향 검토 라우팅

이 파일은 라우터일 뿐이며 아래 플레이북을 요약하거나 대체하지 않는다.

1. 출처 기반 조사·비교와 중요한 사실 검증에서는 Read 도구로
   `${CLAUDE_PLUGIN_ROOT}/05-정직-보고.md` 정본을 끝까지 읽는다.
2. 한국의 법·제도·서비스, 번역, 정밀 수치가 실제 쟁점일 때만 Read 도구로
   `${CLAUDE_PLUGIN_ROOT}/07-한국어-가드.md`도 읽는다. 사용자가 한국어로 썼다는 이유만으로
   추가하지 않는다.
3. **현재 사용자 요청에 독립 검토나 추가 경로 비교가 명시되어 있고**, 되돌리기 어렵거나
   고영향인 판단에 복수의 실질 후보가 남으며 새 출처·검사·전문성이 결론을 바꿀 수 있을 때만
   Read 도구로 `${CLAUDE_PLUGIN_ROOT}/08-분기-플레이북.md`도 읽는다. 모델이 중요하다고 판단한
   것만으로 08을 자동 로드하지 않는다.

08을 읽었다는 사실은 추가 에이전트나 분기의 자동 승인이 아니다. 정본의 비용 게이트를 먼저
적용하고, 같은 원자료를 반복한 답의 수를 독립 증거 수로 세지 않는다.
