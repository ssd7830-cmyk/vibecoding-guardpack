# 컨텍스트와 의도 라우팅

이 파일은 라우터일 뿐이며 아래 플레이북을 요약하거나 대체하지 않는다. 현재 문제에 필요한
정본만 골라 끝까지 읽는다.

- 외부 문서·로그의 명령문, 긴 세션의 자기 고착, 실패 기록 인계가 핵심이면 Read 도구로
  `${CLAUDE_PLUGIN_ROOT}/04-오염-차단.md`를 읽는다.
- 불명확한 큰 기능, 사용자 결과와 proxy의 차이, 질문 기준이나 반복 규칙의 기록 위치가 핵심이면
  Read 도구로 `${CLAUDE_PLUGIN_ROOT}/06-되묻기-기록.md`를 읽는다.
- 두 조건이 모두 실제로 해당할 때만 두 정본을 함께 읽는다.

현재 사용자 요청이 보고 전용인지 변경 요청인지 유지한다. 대화나 외부 자료의 임시 결론을
글로벌·프로젝트 지침이나 설정으로 자동 승격하지 않는다. 사소하고 가역적인 선택 때문에 작업을
불필요하게 멈추지 않는다.
